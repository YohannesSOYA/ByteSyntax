# Tech Stack - Backend

- **Language**: Python 3.10+
- **Framework**: FastAPI
- **ASGI Server**: Uvicorn
- **Database**: 
  - Engine: **MySQL (XAMPP)**
  - ORM: SQLAlchemy
  - Migration: Alembic
- **Validation**: Pydantic v2
- **Authentication**: OAuth2 with JWT (Jose)
- **Email Service**: FastAPI-Mail (SMTP with Gmail)
- **Environment**: python-dotenv & pydantic-settings
